# Results

This directory contains the main outputs generated during the rice drought RNA-seq analysis.

## Results categories

* `DEGs/` — Differentially expressed genes
* `GO/` — Gene Ontology enrichment results
* `KEGG/` — KEGG pathway enrichment results
* `STRING_CytoHubba/` — Protein-protein interaction and hub-gene results
* `RandomForest/` — Machine-learning feature importance and candidate prioritization
* `WGCNA/` — Weighted gene co-expression network analysis
* `final_candidates/` — Integrated candidate-gene results
